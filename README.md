# CyberSys_JDBC_Hibernate_Homework_01

Завдання 1

Вивчіть основні поняття, розглянуті під час уроку.

Завдання 2

Використовуючи додаткове завдання, усі запитання записати в текстовому файлі з нового рядка кожен і, 
використовуючи потоки введення-виведення, порахувати з файлу всі запити та виконати.

Завдання 3

Створіть базу даних з ім'ям «MyJoinsDB», використовуючи Workbench.

Завдання 4

Використовуючи Workbench, створіть 3 таблиці:

У першій таблиці містяться імена та номери телефонів співробітників компанії.

У другій таблиці містяться відомості про зарплати та посади співробітників: головний директор, менеджер, робітник.

У третій таблиці міститься інформація про сімейні становища, дати народження та місця проживання. 

Завдання 5

Використовуючи IntelijIdea та JDBC, зробіть вибірку за допомогою JOIN's для таких завдань:

1.      Отримайте контактні дані співробітників (номери телефонів, місце проживання).

2.      Отримайте інформацію про дату народження всіх неодружених співробітників та їхні номери.

3.      Отримайте інформацію про всіх менеджерів компанії: дати народження та номери телефонів.

Завдання 6

Створити базу даних у Workbench, під'єднати до IntelijIdea та створити тестову таблицю. 
Заповнити її даними за допомогою запитів MySQL у Intelij Idea. 
Використовуючи JDBC, написати приклад виконання всіх запитів.
